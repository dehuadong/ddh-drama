# 小说改编技能实测验收标准

此处是技能研发测试，不是小说改编项目日常检查。实测在隔离样本项目中执行，测试产物不得写入用户真实项目。

## 样本
- 短篇原创/授权样本：端到端完成原著分析至至少一集剧本。
- 长篇节选样本：验证分批阅读、覆盖登记、人物/事件/伏笔跨批追踪。
- 复杂情节样本：验证多视角、交错时间线、人物关系变化、支线合并与新增剧情。

仅提交原创或明确授权文本，不将未经授权的商业小说正文放入仓库。

## 验收任务
1. 原著分析：事实/推断/待确认分离；关键事件可定位；覆盖透明。
2. 改编设计：删、并、压缩、调整、新增等决策有原著依据、戏剧功能、影响、风险和审批。
3. 故事重构：主线因果成立；人物选择驱动事件；副线有明确贡献。
4. 剧集规划：符合集数规格；单集有目标、冲突、行动、转折和后续兑现。
5. 剧本创作：场景可表演可拍；人物对白有区分；场景状态发生变化；前后集连续。
6. 剧本审查：问题有位置、事实、原因、影响和建议；区分客观错误与审美偏好；不擅自改定稿。

## 质量判定
逐项 PASS / FAIL / NEEDS-HUMAN：原著核心与情绪价值、人物动机/关系/弧光、改编追溯、事件因果、伏笔兑现、单集推进、场景目标与阻力、时空/人物/信息/道具连续性、剧本可拍性。

任何 P0/P1 缺陷阻止样本通过。自动检查和模型自评不能单独作为通过依据；至少一轮人工审阅关键因果、人物动机和改编取舍。

## 实测记录
记录样本ID、文本版本与覆盖范围、技能版本、模型/环境、任务规格、产物路径、自动检查结果、人工评分、缺陷、修订和复测结论。
